# FlemNotes - Modern Note-Taking Application

A beautiful, modern PHP-based note-taking application with real-time sync, file uploads, and password protection.

## Features

- ✨ **Modern UI** - Clean, responsive interface with purple theme
- 🎲 **Cool Route Generator** - Auto-generates memorable routes from 227+ mythical, fantasy, and pop culture names
- 🏠 **Welcome Page** - Beautiful landing page with random route suggestions
- 🔄 **Auto-save** - Notes automatically save as you type (2-second delay)
- 📝 **Markdown Preview** - Live markdown rendering with beautiful styling
- 📁 **File Uploads** - Drag & drop or click to upload files (all types except PHP)
- 🔒 **Password Protection** - Optional password protection for notes
- 🌐 **Public/Private** - Toggle note visibility
- 📊 **Statistics** - Real-time character, word, and file count
- 🎯 **SEO Friendly** - Clean URLs with route-based access
- 💾 **SQLite Database** - File-based storage, no MySQL required
- 🔐 **Secure** - PHP files blocked from upload, password hashing

## Requirements

- PHP 7.4 or higher
- SQLite3 extension enabled
- Apache with mod_rewrite enabled (or nginx with similar configuration)
- Internet connection for CDN resources (Marked.js for markdown parsing)

## Installation

### For Development (PHP Built-in Server)

1. Navigate to the project directory:
   ```bash
   cd /home/rohan/Public/flemnotes
   ```

2. Start the PHP development server with increased upload limits:
   ```bash
   php -d upload_max_filesize=50M -d post_max_size=50M -d memory_limit=256M -S localhost:8082 router.php
   ```
   
   Or simply:
   ```bash
   php -S localhost:8082 router.php
   ```
   (The app will try to set limits automatically)

3. Open your browser and visit:
   ```
   http://localhost:8082/mynote
   ```

### For Production (Apache/Nginx)

1. Clone or download this repository to your web server directory:
   ```bash
   cd /var/www/html
   git clone <repository-url> flemnotes
   ```

2. Set proper permissions:
   ```bash
   chmod 755 /var/www/html/flemnotes
   chmod 777 /var/www/html/flemnotes/data
   chmod 777 /var/www/html/flemnotes/uploads
   ```

3. Ensure Apache mod_rewrite is enabled:
   ```bash
   sudo a2enmod rewrite
   sudo systemctl restart apache2
   ```

4. Configure your Apache virtual host to allow .htaccess:
   ```apache
   <Directory /var/www/html/flemnotes>
       AllowOverride All
   </Directory>
   ```

5. Access the application:
   ```
   http://localhost/flemnotes/mynote
   ```

## Usage

### Getting Started

1. **Visit the Home Page**: Navigate to `http://localhost:8082/` or `http://yourdomain.com/`
2. **Welcome Page**: You'll see a beautiful welcome page with:
   - A button to create a random note with a cool generated route
   - 8 example routes to try (e.g., `/phoenixfire`, `/epicwizard`, `/cosmicnova`)
   - Quick access to `/mynote`

### Creating a Note

Simply navigate to any route:
- `http://yourdomain.com/mynote`
- `http://yourdomain.com/project123`
- `http://yourdomain.com/todo`
- Or use any cool generated route like `/dragonbolt`, `/shadowwolf`, `/titanstorm`

The route name must be alphanumeric (letters and numbers only).

### Cool Route Generator

The app includes 227+ names from:
- 🐉 **Mythical creatures**: phoenix, dragon, griffin, titan, zeus, thor, etc.
- ⚔️ **Fantasy elements**: wizard, knight, mage, castle, quest, etc.
- 🎬 **Pop culture**: stark, potter, yoda, neo, gandalf, etc.
- 🏛️ **Epic places**: avalon, asgard, atlantis, wakanda, etc.
- 🌊 **Elements**: fire, ice, storm, shadow, cosmic, etc.
- ✨ **Cool words**: ace, zen, wolf, hawk, bolt, echo, etc.

Routes are generated by combining 2-3 words for memorable, easy-to-type URLs!

See `NAMES_LIST.md` for the complete list.

### Features

1. **Writing Notes**
   - Type in the large text area
   - Markdown is supported
   - Auto-saves after 2 seconds of inactivity

2. **File Uploads**
   - Drag and drop files onto the upload area
   - Click to browse and select files
   - Paste images directly from clipboard
   - All file types allowed except PHP files
   - Files are stored with unique hash suffixes

3. **Password Protection**
   - Enter a password in the "Password Protection" field
   - Password is required to view and edit the note
   - Passwords are securely hashed using bcrypt

4. **Public/Private**
   - Toggle between public and private modes
   - (Note: Currently both modes allow access via URL)

5. **Sharing**
   - Click the "Share" button to copy the note URL
   - Anyone with the URL can access the note (if not password protected)

## Security Features

- PHP file uploads are blocked
- Passwords are hashed using bcrypt
- SQL injection prevention using PDO prepared statements
- XSS prevention with proper HTML escaping
- Database file is protected via .htaccess
- Unique file names prevent overwriting

## Database Schema

### Notes Table
- `id` - Primary key
- `route` - Unique route name
- `content` - Note content
- `password_hash` - Hashed password (optional)
- `is_public` - Public/private flag
- `expires_at` - Expiration timestamp (future feature)
- `created_at` - Creation timestamp
- `updated_at` - Last update timestamp

### Files Table
- `id` - Primary key
- `note_id` - Foreign key to notes
- `original_name` - Original filename
- `stored_name` - Stored filename with hash
- `file_size` - File size in bytes
- `mime_type` - MIME type
- `uploaded_at` - Upload timestamp

## API Endpoints

- `GET api.php?action=get&route={route}` - Get note
- `POST api.php?action=save` - Save note
- `POST api.php?action=upload` - Upload file
- `POST api.php?action=delete-file` - Delete file
- `POST api.php?action=verify-password` - Verify password

## Troubleshooting

### .htaccess not working
- Ensure mod_rewrite is enabled
- Check Apache configuration allows .htaccess overrides
- Verify AllowOverride is set to All

### Permission errors
- Ensure data/ and uploads/ directories are writable
- Check file ownership and permissions

### Database errors
- Ensure SQLite3 PHP extension is installed
- Check data/ directory permissions
