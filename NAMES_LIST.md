## 🚀 How It Works

1. When a user visits the home route (`/` or `/home`)
2. The system shows a welcome page with:
   - A button to create a random note
   - 8 example cool routes to try
   - Quick access to `/mynote`
3. Each route is generated by combining 2-3 words from different categories
4. Routes are short, memorable, and easy to type
5. Each route is unique and can be shared with others

## 💡 Tips for Memorable Routes

- **Keep it short**: 2-3 words max
- **Mix categories**: Combine different types for variety
- **Use themes**: Stick to a theme for related notes
- **Add numbers**: For extra uniqueness when needed
- **Easy to type**: All lowercase, no special characters

## 🎯 Popular Combinations

Based on the algorithm, these types of combinations are most common:
1. Adjective + Noun (e.g., `epicdragon`, `swiftwolf`)
2. Element + Short (e.g., `firebolt`, `shadowfox`)
3. Mythical + Element (e.g., `phoenixfire`, `titanstorm`)
4. Fantasy + Place (e.g., `wizardtower`, `knightcastle`)
